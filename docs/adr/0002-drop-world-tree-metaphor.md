# ADR-0002: 세계수 은유를 폐기하고 페이지별 표현을 채택한다

- 날짜: 2026-08-04
- 상태: accepted

## 배경

사이트는 "세계수를 그리지 않고 레이아웃으로 만든다"는 방향 아래 고정 거터
좌표계(Rail)로 전 페이지를 하나의 축에 묶어 왔다. `CONTEXT.md`는 이 은유를
Living Tree / Rail / Constellation 용어로 정본화했다.

2026-08-04, /about 을 이력서형으로 개편하면서 레일을 제거했고 사용자가 그
결과를 기준점으로 승인했다. 남은 페이지들은 여전히 레일 문법이라 사이트가
두 개의 언어로 갈라졌다. 사용자 결정: "각 카테고리에 맞는 것이 중요하다.
홈·Projects·Writing 은 각각을 최대한 잘 표현해야 한다. 세계수 정본은 없앤다."

## 결정

**세계수 은유와 그 구현(Rail)을 전면 폐기한다. 페이지를 하나의 은유로 묶지
않고, 각 페이지가 자기 성격을 가장 잘 표현하는 레이아웃을 가진다.**

사이트를 하나로 묶는 것은 은유가 아니라 /about 에서 확립된 디테일 문법이다:

- 구획은 1px 헤어라인(`border`)만 쓴다 — 배경 전환·카드·그림자 없음
- 섹션 제목은 영문 단독(`text-xl`), 페이지 제목은 `text-2xl`
- 날짜는 점 표기(`yyyy. MM. dd.`) + `tabular-nums`
- 분모 없는 수치·게이지·뱃지 금지

같은 결정으로 내비게이션 라벨 **Portfolio 를 Projects 로 교체**한다(/about
섹션 제목·사용자 언어와 일치). URL `/portfolio` 는 유지한다 — 라벨 교체이지
콘텐츠 이주가 아니다.

## 근거

- **은유가 콘텐츠보다 먼저 온 것이 반복된 실패 원인이었다.** 프로토타입 6종
  전멸(2026-07-25)도, 빈 Roots 영역(ADR-0001)도 같은 뿌리다.
- **/about 이 증명했다.** 레일 없이도 헤어라인·영문 제목 문법만으로 사이트의
  일관성이 유지됐고, 페이지 성격(이력서)은 더 분명해졌다.
- **레일은 인덱스형 페이지에서만 성립하는 문법이었다.** 글 상세에서 이미
  제외됐고(좌표가 날짜 하나), /about 에서도 제외됐다. 예외가 절반이면
  좌표계가 아니다.

## 버린 선택지

- **레일 유지 + /about 만 예외** — 두 언어가 공존해 위화감이 계속된다.
- **/about 을 레일로 되돌리기** — 5라운드 첨삭으로 수렴한 결과를 버리게 된다.

## 영향

- `CONTEXT.md`: Living Tree / Rail / Constellation 항목 삭제, Portfolio →
  Projects 개명, 서문에서 "살아 있는 세계" 서사 제거.
- `src/components/layout/rail.tsx` 삭제, `globals.css` 의 rail 토큰·규칙 삭제.
- 홈·/writing·/portfolio·/portfolio/[slug]·/tags 를 /about 문법으로 재구성.
- `docs/design/living-personal-site.md` 에서 세계수·도서관·우주 서사 제거.

## 되돌리는 법

되살릴 이유가 생기면 이 커밋 이전의 `rail.tsx` 와 globals.css 의 rail 블록을
복원하면 된다. 단, 프로토타입 6종과 마찬가지로 "은유 먼저, 콘텐츠 나중"의
징후라면 되살리지 않는다.
