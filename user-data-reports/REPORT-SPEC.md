# 오늘의할인 리포트 작성 기준

## 정본과 적용 범위
이 파일은 사용자가 승인한 최종 기준이다. SOURCES.md의 승인 발언을 근거로 한다. 초기 제안인 category_change 포함, 75% 목표, 노출 세션 퍼널은 현재 기준이 아니다.

## 유지하는 정의
- 제품 가치: 실제로 받을 수 있는 큰 할인 혜택을 쉽게 찾도록 할인 정보를 제공한다. 할인액이 같으면 조건이 적을수록 유리하다.
- 활성 사용자: 집계 기간 안에 offer_link_click 또는 banner_click을 한 고유 person_id. 두 이벤트는 합집합으로 중복 제거한다.
- 방문자: 같은 기간 $pageview를 발생시킨 고유 person_id. 활성 사용자와 구분한다.
- WAU: Asia/Seoul 월요일 00:00부터 다음 월요일 00:00 미만의 활성 사용자 수.
- 핵심 지표: 주간 할인 선택 도달률 = 주간 활성 사용자 / 주간 방문자 × 100. 구매나 앱 실행 성공으로 해석하지 않는다.
- 제외 기준: 기존 리포트 SQL은 raw_cohort_people의 cohort_id=464290, version=54와 static_cohort_people의 cohort_id=500325를 제외했다. 현재 필터와 차이가 있는지 확인하고 과거 재현 결과를 기록한다. 팀원 전부 제외는 당시 사용자 지정 가정이며 독립 확인 사실이 아니다.
- Retention: 각 기준 주의 활성 사용자가 정확히 1~4주 뒤 같은 활성 행동을 하는 비율. 첫 방문 기준이 아니다. W+4의 한 주까지 종료된 코호트만 포함한다. 통합 곡선은 같은 성숙 코호트를 W+0~4 모두에 사용하고 분자 합 / 분모 합으로 계산한다. 사용자 한 명은 여러 기준 주에 속할 수 있다.

## 갱신과 비교
- 작성일 현재 진행 중인 주와 종료된 주를 구분한다. 완료 주까지만 목표 분포와 확정 비교에 사용한다.
- 마지막 관찰은 최근 완료된 2주와 그 이전 2주를 비교한다. 실제 스프린트 날짜와 관측 기간을 혼동하지 않는다.
- 주별 WAU는 각각 보존한다. 2주 전체 인원과 도달률은 기간 전체에서 중복 제거해 재조회한다. WAU 합계나 주간 비율 평균으로 대체하지 않는다.
- 목표는 관측 시작 이후 완료 주별 도달률의 75퍼센타일을 선형 보간해 구하고 정수 %로 반올림한다. 분포에는 계산값을 소수 둘째 자리까지 표시한다.
- 직전 기간의 성과는 그때 확정한 목표로 평가한다. 이번 갱신 목표를 과거에 소급하지 않는다. 두 주 모두 당시 목표 이상이어야 달성이다.
- 인원 변화는 명과 %, 도달률 변화는 %p로 표현한다. 숫자 나열은 표에, 해석은 2주 전체 변화 중심으로 쓴다.

## 문서와 표현
- template.html의 도입부, 절 구성과 스타일을 유지한다. 미션 8항목(정의, 활성 데이터, WAU/W+4, 해석, 핵심 지표, 목표/근거, 현재값, 해석)을 모두 충족한다.
- 목표 절은 지난 목표와 주별 달성 결과, 최종 판정을 먼저 보여주고 다음 관측에 적용할 목표와 분포 근거를 이어서 배치한다. 재계산 후 목표가 같으면 그 사실을 명시한다.
- 비교 문단은 이전값과 현재값, 변화량을 굵게 강조하고 비교 주의사항은 보조 문단으로 구분한다.
- 마지막은 확인한 것, 아직 판단하기 어려운 것, 다음에 확인할 것으로 구성한다. 확인한 것은 기간과 수치로 쓴다.
- 원인, 적정 리텐션 수준, 재방문 주기의 적절성은 근거가 없으면 미확인 질문으로 남긴다. 높다/낮다/적다 같은 평가는 비교 기준이 있을 때 쓴다.
- 문장은 앞뒤 대화 없이 이해되어야 한다. 중복 설명, 방어적인 단서, 작업 과정 설명을 줄인다.
- 그래프 축은 시작일~종료일을 표시하고 리텐션 점마다 값을 표시한다. 퍼센타일 위치는 실제 값의 간격에 비례시킨다.
- 그래프와 해당 수치를 함께 배치한다. 숫자 2열 표는 같은 폭으로 중앙 정렬하고 설명형 표는 왼쪽 정렬한다. 모바일 가로 스크롤 그래프는 최신 날짜부터 보인다.
- 과거 GA 이미지는 원본과 당시 날짜 설명을 유지하며 최신 자료로 표현하지 않는다. 레이아웃 수정 시 내용과 수치를 바꾸지 않는다.

## 완료 조건
과거 재현, 기간 경계, 제외 조건, 중복 제거, Retention 분모, 퍼센타일, 당시 목표 판정, 모든 표시 수치 대조, 모바일/데스크톱 확인 결과를 evidence에 남긴다. 조회 실패를 과거 수치로 채우지 않는다.
