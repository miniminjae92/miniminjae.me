# 유저 데이터 리포트 작업 지침

1. 작성과 갱신 전에 REPORT-SPEC.md와 SOURCES.md를 읽는다.
2. reports의 지난 결과물을 보존하고, template.html을 복사해 날짜별 결과물을 만든다.
3. 지표 정의, 도입부, 절 순서, 기존 설명과 디자인은 유지한다. 새 데이터와 이에 따른 해석을 갱신한다. 기준 변경은 사용자와 논의한다.
4. PostHog 프로젝트 548055의 실제 데이터를 조회한다. 브라우저의 로그인 세션은 ego-browser로 사용한다.
5. 과거 8개 완료 주와 지난 리포트 비교 기간을 먼저 재현한다. 불일치는 원인을 기록하고, 기존 값에 맞추려고 필터를 임의 변경하지 않는다.
6. 집계 SQL, 응답, 기준 시각, 적용한 제외 조건을 evidence에 보존한다. 인증정보와 개인별 식별자는 보관하지 않는다.
7. 표와 그래프, 본문, 목표 분포, 마지막 관찰의 숫자를 대조한다. 주간 값과 2주 중복 제거 값을 구분한다.
8. 데스크톱과 모바일에서 그래프, 표, 수식, 최신 기간 표시를 확인한다. 완료 보고에 실제 확인 범위와 결과물 경로를 적는다.
9. SQL과 작업 과정은 독자용 본문 대신 evidence에 둔다. 제출과 배포는 별도 요청이 있을 때 진행한다.
