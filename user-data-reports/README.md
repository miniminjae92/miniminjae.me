Sprint 1의 파일명 날짜는 기존 파일의 게시 커밋(2026-09-30)을 기준으로 정했다. 과거 두 파일은 기존 공유 파일과 바이트 단위로 동일하다.

`public/shared/`의 기존 파일은 공유 URL을 유지하는 배포 사본이다. 이후에는 `reports/`에서 작성하고 검토 후 배포 요청 시 해당 결과물을 `public/shared/`에 복사한다. 배포 사본만 직접 수정하지 않는다. 외부 배포와 제출은 별도 요청 시 진행한다.

`template.html`은 합의한 구성과 디자인의 기준이며, `evidence/`에는 집계와 검증 근거를 보관한다.
